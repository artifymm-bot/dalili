# طارق – دليل المنازل لمحصل المياه

نسخة ويب تجريبية مهيأة للموبايل لاختبار فكرة اختيار قطعة من مخطط الوحدة المحلية وعرض بيانات المنزل.

## التشغيل
- افتح `index.html` مباشرة أو انشر المستودع باستخدام GitHub Pages.
- اضغط على قطعة ضمن المناطق التفاعلية لتحديدها.
- تسجيل دخول المدير التجريبي: كلمة المرور `1234`.
- المحصل في وضع العرض فقط.
- المدير يستطيع إدخال اسم العميل ورقم الهاتف والملاحظات ورفع صور المنزل والعداد والصور الإضافية.

## تنبيه مهم
هذه نسخة إثبات فكرة (Prototype) وليست نظاماً إنتاجياً:
- بيانات المدير والصور تحفظ في `localStorage` على المتصفح والجهاز نفسه فقط.
- لا توجد مزامنة بين أجهزة المدير والمحصل ولا مصادقة حقيقية.
- كلمة المرور التجريبية ظاهرة داخل كود الواجهة ولا توفر حماية أمنية.
- حدود القطع المرسومة فوق المخطط تقريبية ومحدودة لاختبار التفاعل، ويجب تدقيقها يدوياً مع المخطط الأصلي قبل الاعتماد.
- الصور تضاف محلياً في المتصفح ولا ترفع إلى خادم.

## النشر على GitHub Pages
من إعدادات المستودع: Settings → Pages → Deploy from a branch → main → /(root) → Save.
