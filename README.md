# دليلي – نموذج تجريبي لاستعراض المواقع

صفحة ويب عربية متجاوبة بهوية مؤسسية خضراء، لاستعراض قطع المخطط وبيانات المواقع والصور.

## تجربة النموذج
- افتح `index.html` أو رابط GitHub Pages.
- اضغط على قطعة في المخطط أو ابحث برقمها.
- ستظهر بيانات عميل افتراضية وأربع صور توضيحية.
- يمكن تكبير المخطط وتصغيره، وفتح الصور بحجم أكبر.
- لا توجد حالياً أزرار دخول مدير أو محصل، ولا شاشة صلاحيات؛ أزيلت من النسخة التجريبية حسب المطلوب.

## ملفات العرض
- `assets/demo-plan.svg`: مخطط توضيحي جديد مرسوم بصيغة SVG.
- `assets/demo-home.svg` و`assets/demo-house-2.svg`: صور منازل توضيحية.
- `assets/demo-meter.svg` و`assets/demo-pipes.svg`: صور عداد وتوصيلات مياه توضيحية.

## تنبيه
هذه نسخة عرض لإيصال الفكرة فقط. الهوية البصرية مستوحاة من الطابع المؤسسي السعودي، ولا تستخدم شعار جهة حكومية أو تدّعي اعتماداً رسمياً. المخطط والصور والبيانات افتراضية وليست بيانات عملاء حقيقية أو مخططاً هندسياً معتمداً. بعد موافقة العميل نستبدلها بالمخطط الأصلي والصور والبيانات الصحيحة، ثم نبني نظام الإدارة والمزامنة وقاعدة البيانات.
